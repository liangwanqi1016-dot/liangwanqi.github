# 5주차 · 음식 취향과 브라우저 저장소

- 8문항과 4가지 결과, 식사 템포·음식 삽화·세 언어를 유지했습니다.
- sessionStorage `week5.draft`: 현재 탭의 참여 ID, `campus-food-v2` 버전, 닉네임, 현재 문항과 답변. 새로고침 후 이어하기로 복원합니다.
- localStorage `week5.history`: ID·버전·답변·결과·완료 시각, 최근 20개. 페이지를 다시 열어 기록과 결과를 확인할 수 있습니다.
- 기록별 삭제, 임시 답변 삭제, 게임 전체 삭제를 제공합니다. 전체 삭제는 두 키와 메모리·화면을 함께 초기화하며 다른 주차 저장소를 지우지 않습니다.
- 저장 데이터 보기는 현재 저장소를 다시 읽습니다. 잘못된 JSON·버전·답변을 검증하며 저장 제한 때 안내합니다. 같은 참여 ID 중복을 막고, 같은 버전의 두 참여는 같은 선택 개수를 비교합니다.
- 저장은 사용자 기기의 브라우저에서만 이루어집니다. 다른 기기로 자동 동기화되거나 서버에 전송되지 않습니다.
- 확인 순서: 두 문항 답변 → 같은 탭 새로고침 → 이어하기 → 완료 → 재방문 → 기록/초안/전체 삭제. 기록이 없는 과거 버전은 친구 비교에서 제외합니다.
- AI 도움: 저장 검증과 화면·데이터 초기화를 함께 처리하도록 수정했습니다. 실제 새로고침과 데이터 복원은 브라우저에서 확인합니다.
